# Compta Canard — dépôts de mises à jour

Ce dépôt est réservé aux paquets de mise à jour validés de Compta Canard.

## Règles de publication
- Une version publiée doit être identifiée par un numéro clair (ex. `v2.1.0`).
- Le paquet doit contenir uniquement les fichiers du programme, jamais la base de données de l'utilisateur.
- Chaque paquet doit être accompagné d'une somme SHA-256 et de notes de version.
- Toute mise à jour doit sauvegarder les données locales avant installation.
- Le programme doit vérifier l'intégrité du paquet avant de l'installer.
- Aucun jeton d'accès GitHub ou Microsoft ne doit être inclus dans l'application.
